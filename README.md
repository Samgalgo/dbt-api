# DAILY BLESSING TRACKER BACKEND

We often forget that the small things in life are what makes life beautiful and worth living it. Daily Blessing Tracker DBT or is an app that aims to help you track and focus on the everyday blessings we have in life. Made with love, joy and hunger to make this world a better place.
